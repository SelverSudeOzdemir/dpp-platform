# Kocaer DPP — Digital Product Passport

CIRPASS uyumlu Dijital Ürün Pasaportu sistemi.

## Hızlı Başlangıç

```bash
# Projeyi başlat
docker-compose up

# API: http://localhost:8000
# API Docs: http://localhost:8000/docs
# Frontend: http://localhost:3000
```

## Yapı

- `backend/` — FastAPI + PostgreSQL
- `frontend/` — Next.js
- `database/` — Migration ve seed dosyaları
- `docs/` — Mimari kararlar

## Veritabanı Şeması

Şema versiyonu v2.0.0 — bkz. `database/schema_ref.sql`
